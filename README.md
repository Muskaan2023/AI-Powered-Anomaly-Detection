# AI-Powered User Behavior Analytics & Anomaly Detection

This project detects anomalous user behavior using Machine Learning (Isolation Forest) and visualizes security events through an interactive Streamlit dashboard.

## Features

- Synthetic user generation
- Normal login log generation
- Attack log simulation
- Feature engineering
- Isolation Forest anomaly detection
- Risk scoring
- Interactive Streamlit dashboard
- High-risk alert detection
- CSV export functionality

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Streamlit
- Plotly
- Faker
